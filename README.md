# 健身网站项目

## 项目概述
这是一个为初级健身者设计的健身网站，提供一个月的训练计划，并计划在未来实现动态生成下个月计划的功能。

## 项目目标
1. 创建一个用户友好的健身网站
2. 提供一个月的训练计划（前胸、手臂、腹部、背部、腿部）
3. 每次训练30-45分钟，每周3-4次
4. 记录训练数据，为下个月计划提供依据
5. 未来实现动态生成下个月计划的功能

## 技术栈
- 前端：HTML, CSS, JavaScript
- 后端：Node.js (可选)
- 数据存储：JSON文件或本地数据库

## 训练计划结构
- **第1周**：基础适应期
- **第2周**：强度提升期
- **第3周**：巩固期
- **第4周**：测试与调整期

## 每周训练安排
- **周一**：前胸 + 手臂
- **周三**：背部 + 腹部
- **周五**：腿部
- **周六**（可选）：全身轻度训练

## 未来功能规划
1. 训练数据记录
2. 进度追踪图表
3. 动态计划生成算法
4. 个性化调整建议
5. 移动端适配

## 开发计划
1. 第一阶段：基础网站搭建（1-2天）
2. 第二阶段：训练计划展示（2-3天）
3. 第三阶段：数据记录功能（3-4天）
4. 第四阶段：动态计划生成（4-5天）

## 使用说明
1. 打开 `index.html` 开始使用
2. 选择当天的训练计划
3. 记录训练数据
4. 每周回顾进度
